# 联系页面配置说明

## 功能概述

联系页面（/contact）的联系信息卡片现在可以通过后台管理进行配置。

## 可配置内容

红框内的4个联系信息卡片：

1. **电话咨询** - 电话号码和服务时间
2. **邮箱联系** - 邮箱地址和回复时效
3. **公司地址** - 简写地址和备注
4. **在线咨询** - 服务标题和描述

## 配置项列表

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `phone` | +86 400 888 8888 | 联系电话 |
| `phone_time` | 周一至周日 9:00-21:00 | 电话服务时间 |
| `email` | info@huananliu.com | 联系邮箱 |
| `email_reply` | 24小时内回复 | 邮箱回复时效 |
| `address` | 广州市天河区珠江新城 | 公司地址（卡片显示） |
| `address_full` | 广州市天河区珠江新城华夏路30号 | 完整地址（地图区域） |
| `address_note` | 欢迎预约到访咨询 | 地址备注 |
| `online_title` | 7×24小时在线 | 在线服务标题 |
| `online_desc` | 随时为您解答疑问 | 在线服务描述 |
| `business_hours` | 周一至周日 9:00-21:00 | 营业时间 |

## 如何配置

1. 登录后台管理：http://localhost:3002
2. 进入「网站管理」→「网站配置」
3. 切换到「联系方式」标签
4. 修改各项配置
5. 点击「保存设置」

## 前端效果

前台联系页面会自动获取最新配置，无需重启服务。

访问地址：http://localhost:3000/contact
