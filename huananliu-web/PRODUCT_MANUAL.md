## 1. 产品概述

### 1.1 产品定位
华南留学是一个全栈式留学服务平台，为有意向出国留学的学生提供院校查询、案例参考、顾问咨询、资讯获取等服务。

### 1.2 核心功能模块

- 学校展示系统
- 案例展示系统 (含明星案例)
- 顾问展示系统
- 新闻资讯系统 (含推荐新闻)
- 服务展示系统
- 留学评估表单
- 用户评价轮播
- 后台管理系统

---

## 2. 系统架构

### 2.1 部署架构
```
用户访问
    │
    ├───> 官网前端 (localhost:3000)
    │
    ├───> 后台管理 (localhost:3002)
    │
    └───> 后端API (localhost:3001) ───> MySQL数据库
```

### 2.2 技术栈
| 层级 | 技术 |
|------|------|
| 官网前端 | React 18 + Vite + TailwindCSS |
| 后台前端 | React 18 + Ant Design |
| 后端服务 | Node.js + Express + Sequelize |
| 数据库 | MySQL 8 |
| 认证 | JWT |

## 3. 功能详解

### 3.1 学校展示系统

展示合作院校信息，支持按国家、排名筛选。

**数据字段**:
- name: 学校中文名称
- name_en: 学校英文名称
- country: 国家
- city: 城市
- ranking: 排名
- description: 简介
- logo: Logo图片
- images: 校园图片

**前端展示**:
- 首页：热门学校推荐卡片
- 学校列表页：筛选 + 列表
- 学校详情页：完整信息展示

---

### 3.2 案例展示系统

展示成功留学案例，含明星案例功能。

**数据字段**:
- student_name: 学生姓名
- school_id: 录取学校
- major: 专业
- degree: 学位
- background: 学生背景
- result: 申请结果
- content: 案例详情

**明星案例字段**:
- is_featured: 是否明星案例
- feature_sort: 排序
- feature_highlight: 亮点标签
- feature_bg: 背景色渐变

---

### 3.3 顾问展示系统

展示留学顾问信息。

**数据字段**:
- name: 姓名
- title: 职称
- avatar: 头像
- specialties: 专长领域
- experience: 从业年限
- description: 简介

---

### 3.4 新闻资讯系统

展示留学相关新闻资讯，含推荐功能。

**数据字段**:
- title: 标题
- content: 内容
- summary: 摘要
- cover_image: 封面图
- category: 分类

**推荐字段**:
- is_recommended: 是否推荐
- recommend_sort: 推荐排序

---

### 3.5 服务展示系统

展示提供的留学服务。

**数据字段**:
- title: 服务名称
- description: 服务描述
- icon: 图标
- content: 详细内容

---

### 3.6 留学评估表单

用户填写留学意向，获取初步评估。

**表单字段**:
- name: 姓名
- phone: 电话
- target_country: 目标国家
- target_degree: 目标学位
- gpa: GPA成绩
- language_score: 语言成绩
- message: 留言

---

### 3.7 用户评价轮播

首页展示学生评价，自动轮播。

**数据字段**:
- student_name: 学生姓名
- avatar: 头像
- school: 录取学校
- major: 专业
- content: 评价内容
- sort_order: 排序

---

### 3.8 后台管理系统

管理前端展示的所有内容。

**功能模块**:
- Banner管理
- 学校管理
- 案例管理 (含明星案例设置)
- 顾问管理
- 新闻管理 (含推荐设置)
- 服务管理
- 评价管理
- 数据统计

## 4. 运营指南

### 4.1 内容更新流程

1. 登录后台管理系统 (默认端口3002)
2. 选择对应模块
3. 添加/编辑/删除内容
4. 前端自动更新

### 4.2 明星案例设置

1. 进入案例管理
2. 点击"设为明星"按钮
3. 配置亮点标签和背景色
4. 调整排序

### 4.3 推荐新闻设置

1. 进入新闻管理
2. 编辑新闻
3. 勾选"推荐到首页"
4. 设置排序值

## 5. 常见问题

**Q: 如何添加新学校?**
A: 登录后台 -> 学校管理 -> 新增学校

**Q: 如何修改首页Banner?**
A: 登录后台 -> Banner管理 -> 编辑

**Q: 如何查看用户提交的评估表单?**
A: 登录后台 -> 消息/预约管理
